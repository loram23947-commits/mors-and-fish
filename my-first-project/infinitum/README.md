# INFINITUM — локальная версия для согласования

Откройте index.html двойным щелчком: установка зависимостей не нужна.
Для просмотра через сервер выполните в этой папке:

    node server.cjs

Адрес на компьютере: http://localhost:4173
Для смартфона в той же Wi-Fi сети откройте http://IP-КОМПЬЮТЕРА:4173.
IP можно узнать командой ipconfig. Если Windows запросит доступ сервера к сети, разрешите его только для вашей частной сети. Остановка сервера: Ctrl+C.

## Редактирование

site.config.js — все основные тексты, карточки, вопросы, две Telegram-ссылки и пути изображений. Названия разделов и кнопок находятся в index.html; оформление — в styles.css; поведение — в app.js. При изменении заголовка и описания обновите также метаданные в index.html.

## Оригинальные изображения

Все три предоставленных JPG скопированы без изменений: assets/hero.jpg — композиция с кругами на первом экране; assets/game.jpg — композиция с лучами в разделе Игры; assets/mask.jpg — отдельная маска в закреплённом меню и favicon. Пропорции сохранены, обрезка, фильтры и удаление фона не применялись.

При выборе постоянного домена замените относительный og:image в index.html на абсолютный HTTPS-адрес assets/hero.jpg, добавьте og:url и canonical.

## Публикация после согласования

Загрузите index.html, styles.css, app.js, site.config.js и папку assets на статический хостинг с HTTPS. Файлы server.cjs и prepare.cjs публиковать не нужно. prepare.cjs — служебный однократный импорт из исходного задания; повторный запуск перезаписывает ваши изменения site.config.js.

Юридические сведения можно добавить через поле legal в site.config.js. Политика, если понадобится, добавляется отдельным документом со ссылкой в подвале. Реквизиты и сведения о владельце не придуманы. Аналитика и сторонние шрифты не подключены.

Сайт не публиковался. Оригинальные изображения подключены. До окончательной приёмки нужна визуальная проверка на компьютере и телефоне.
